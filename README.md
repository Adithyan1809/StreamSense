# StreamSense

A Streamlit application for asking questions about YouTube video transcripts.

## Setup

1. Create and activate a Python virtual environment.
2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

3. Copy `.env.example` to `.env` and set `GOOGLE_API_KEY`.
4. Start the app:

   ```powershell
   streamlit run app.py
   ```

The application implementation will be added in the next step.
